Como usar o painel

Este painel mostra os chamados do banco de dados do bot de suporte. Todo mundo que entra vê os mesmos chamados: nada do que aparece aqui fica guardado no seu navegador — o quadro lê e escreve no banco, e a tela se atualiza sozinha a cada 30 segundos.

  • Criar abre o formulário de um chamado novo. Escolha o tipo primeiro: ele decide se o formulário pede os campos de chamado interno (setor de origem, sistema afetado, impacto) ou de franquia (unidade, franqueado, custo, urgência comercial).
  • Arraste os cartões entre as colunas para mudar a situação. Com “Avisar usuário ao mover” ligado, o solicitante recebe mensagem no WhatsApp — tarefa criada aqui não tem telefone, então não recebe nada.
  • Clique em um cartão para ver e editar a classificação completa, comentar, anexar arquivo, marcar dependência e avaliar. Cada campo é gravado no banco assim que você sai dele.
  • Filtre por texto, assunto, setor, tipo, prioridade ou responsável na barra de ferramentas.
  • Assuntos é o menu que o cliente lê no WhatsApp; Setores são as áreas internas que atendem; Pessoas é quem pode ser responsável. As três listas são compartilhadas.
  • Resumo mostra os números do período por assunto, por setor e por tipo.

Conectar ao banco de chamados

O quadro lê os chamados pela API do bot de suporte. Cole o token de acesso (PAINEL_TOKEN, ou INTERNAL_API_TOKEN se aquele não estiver configurado).

Sem marcar, o token some ao fechar a aba. Ele permite alterar chamados e disparar mensagem de WhatsApp — não deixe gravado em máquina compartilhada.

Assuntos do atendimento

Esta é a lista que o bot oferece no WhatsApp depois da saudação. O número de cada opção é calculado na hora, entre os assuntos ativos — desativar um não deixa buraco na numeração. Exibição é o que o cliente lê; nome é o interno, para os relatórios.

Os dois interruptores são diferentes. No WhatsApp desmarcado é o assunto de uso interno: ele sai do menu da conversa e continua aqui, no seletor de assunto do chamado — é assim que a TI classifica o que o cliente não deve ver na lista. Ativo desmarcado tira o assunto dos dois lugares, preservando os chamados que já o usam. Marcar um assunto como interno leva junto os sub-assuntos dele: a conversa desce um nível por vez, e ninguém chega ao que está embaixo de uma opção que não é oferecida.
