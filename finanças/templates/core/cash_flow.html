Como calculamos
  1. Saldo inicial: tudo que entrou menos tudo que saiu até o mês anterior. Nenhum lançamento futuro entra no saldo de hoje.
  2. Certo: {{ f.future_count }} lançamento(s) já existentes com data futura — {{ f.counts.card|default:0 }} parcela(s) de cartão, {{ f.counts.fixed|default:0 }} conta(s) fixa(s), {{ f.counts.loans|default:0 }} parcela(s) de empréstimo, {{ f.counts.other|default:0 }} outra(s) e {{ f.counts.income|default:0 }} receita(s).
  3. Estimado: o gasto do dia a dia ainda não lançado. Usamos a {% if f.scenario == 'base' %}mediana{% elif f.scenario == 'pessimista' %}faixa alta (percentil 75){% else %}faixa baixa (percentil 25){% endif %} dos gastos manuais/importados dos últimos meses completos: {% for h in f.history %}{{ h.label }} {{ h.expense|brl }}{% if not forloop.last %}, {% endif %}{% empty %}sem histórico ainda{% endfor %}. → {{ f.estimate.expense|brl }}/mês{% if f.estimate.income %}; receitas variáveis {{ f.estimate.income|brl }}/mês{% endif %}.
  4. Mês atual: o que já passou é realizado; do dia seguinte até o fim do mês somamos os vencimentos certos e a parte proporcional do estimado.
  5. Aportes em investimento e parcelas de empréstimo nunca entram no "variável" — ou já estão lançados, ou não são gasto do dia a dia.
